개인정보를 지키는 로컬 AI 전략

외부 클라우드 AI에 대한 프라이버시 반감을 강점으로 바꾸기 · 2026-07-27

핵심: haru는 이미 로컬 AI(Ollama)를 기본값으로 씁니다. 즉, 특별한 설정 없이도 대화·할일 데이터가 사용자 기기를 벗어나지 않습니다. 문제는 이 강점이 사용자에게 보이지 않는다는 점, 그리고 외부 제공자로 바꿀 때 데이터가 나간다는 사실이 충분히 고지되지 않는다는 점입니다. 아래 제안은 "로컬 우선"을 신뢰 신호이자 App Store 차별점으로 끌어올리는 방법입니다.

1지금 갖춘 것 (출발점)

✓ Ollama 로컬이 기본 제공자 ✓ 외부(OpenAI/커스텀)는 선택 ✓ SSRF 가드 · localhost만 허용 ✓ API 키 마스킹 ✓ 설치 모델 드롭다운 + 8B+ 권장 안내 ✗ 프라이버시 상태가 UI에 안 보임 ✗ 외부 전환 시 데이터 전송 경고 없음

기술적 토대는 이미 프라이버시 친화적입니다. 남은 건 이 사실을 사용자가 믿을 수 있게 드러내고, 실수로도 데이터가 새지 않도록 잠그고, 로컬 설치 마찰을 줄이는 것입니다.

2제안 — 즉시 (로우행잉)

즉시 · 소

🔒 "온디바이스" 배지

Ollama 사용 중일 때 AI 패널·설정에 "로컬 처리 · 데이터가 기기를 벗어나지 않음" 배지를 상시 표시.

이미 로컬인데 안 보임 → 가장 값싼 신뢰 획득. 연결 상태 점(●) 옆에 붙이면 끝.

즉시 · 소

⚠️ 외부 전환 경고

제공자를 OpenAI/커스텀으로 바꿀 때 "대화·할일 내용이 <업체> 서버로 전송됩니다"를 명확히 고지하고 동의 받기.

몰라서 새는 걸 막는 최소 장치. 설정의 provider 변경 지점에 확인 모달 한 개.

즉시 · 중

🔐 로컬 전용 잠금 (프라이버시 모드)

설정에 토글 하나: 켜면 외부 제공자 자체를 비활성화. 실수로도, 나중에도 데이터가 나갈 수 없음.

프라이버시 민감/기업 사용자에게 "확실한 보장". provider 드롭다운을 Ollama로 고정.

즉시 · 중

👁 전송 데이터 미리보기

모델에 실제로 보내는 컨텍스트(할일 요약)를 펼쳐 볼 수 있게 노출. "무엇이 나가는지" 투명화.

이미 buildAiTaskContext로 만든 요약이라 그대로 보여주기만 하면 됨.

3제안 — 중기 (온보딩·가시성)

중기 · 중

⚡ 원클릭 로컬 온보딩

Ollama 미설치를 감지 → 설치 안내/딥링크, 그리고 추천 모델 자동 pull(한국어용 8B급).

로컬 AI 최대 마찰 = 설치. 이걸 줄이면 로컬을 기본으로 쓰는 사용자가 급증. (연결 실패 화면에서 바로 유도)

중기 · 소

📡 네트워크 인디케이터

AI 호출이 어디로 나가는지 표시. localhost면 "로컬", 외부면 도메인 노출. 이그레스 가시성.

"진짜 로컬인지" 눈으로 확인. 로컬일 땐 외부 트래픽 0임을 증명.

중기 · 소

✈️ 오프라인 우선 강조

로컬 모델은 네트워크 없이도 동작(이미 그럼). "비행기 모드에서도 AI가 됩니다"를 명시적 가치로.

클라우드 to-do 앱과의 즉각적 대비. 마케팅 포인트.

중기 · 중

🇰🇷 한국어 로컬 모델 큐레이션

설치 모델 드롭다운에 한국어 품질 추천 배지. EXAONE/EEVE 등 한국어 특화 모델 원클릭 설치.

"로컬은 한국어가 약하다"는 반론을 정면 해소. (드롭다운·8B+ 힌트는 이미 구현됨)

4제안 — 장기 (강한 해자)

장기 · 대

📦 내장 런타임 (Ollama 의존 제거)

node-llama-cpp 등으로 앱 안에서 모델을 직접 구동. 별도 설치 0, 완전 자족.

최고의 프라이버시·최저 마찰("설치할 게 없음"). 대신 번들 크기↑·엔지니어링 부담↑. 소형 모델 번들 + 대형은 옵션.

장기 · 중

🔎 로컬 RAG / 임베딩

Ollama 임베딩으로 관련 할일만 검색해 컨텍스트 구성. 전량 전송 대신 필요한 것만, 전부 로컬.

할일이 많아도 정확·저비용. 프롬프트 컨텍스트 품질↑ (현재는 상위 ~48개를 통째로 전달).

5트레이드오프 & 완화

우려실제완화책
한국어 품질 3B(llama3.2)는 한국어에 다른 언어를 섞음(실측 확인). 8B+/특화 모델은 깨끗. 8B+ 권장 안내(구현됨) · 한국어 특화 모델 큐레이션 · 프롬프트 강화(구현됨)
속도 큰 로컬 모델은 클라우드보다 느릴 수 있음(기기 성능 의존). 기기별 모델 크기 안내 · 스트리밍으로 체감 개선(구현됨) · 소형↔대형 선택권
설치 마찰 Ollama 설치 + 모델 pull이 진입장벽. 원클릭 온보딩(중기) · 장기적으로 내장 런타임으로 마찰 0
RAM/디스크 8B≈5GB, 20B≈13GB. 저사양 기기 부담. 드롭다운에 크기/권장 사양 표기 · 기본은 경량, 대형은 옵트인

✓권장 로드맵

1
이번 릴리스: 온디바이스 배지 + 외부 전환 경고 + 로컬 전용 잠금. (작음, 큰 신뢰 효과 — App Store 심사 전에 넣기 좋음)
2

3
이후: 한국어 모델 큐레이션 → 로컬 RAG → (여력 되면) 내장 런타임. (해자)
