한 가지 바로잡을 것

"인증받고 나면 화면만 꾸미면 된다"는 순서가 아닙니다. 심사는 앱과 스토어 화면을 같이 봅니다. 둘을 묶어서 한 번에 제출하고, 심사관은 양쪽을 대조합니다.

그래서 스크린샷이 실제 앱과 다르거나, 설명에 적힌 기능이 앱에 없으면 제출 전체가 반려됩니다. 앱만 따로 승인받아 두고 나중에 화면을 마음대로 바꾸는 구조가 아닙니다.

처리가 끝나면

  1. App Store Connect → Greenday → 왼쪽 빌드 탭에서 2.0.1 확인
  2. 버전 페이지 → 빌드 섹션 → + → 방금 것 선택
  3. 스토어 화면 채우기 (붙여넣기용 문서 참고)
  4. App Privacy → No, we do not collect data from this app
  5. App Review Information → 메모에 준비된 영문 붙여넣기
  6. 심사에 추가 → 제출
처리 중 이메일이 올 수 있습니다. 업로드 검증을 통과해도 Apple 서버가 추가로 검사하는 항목이 있어서, "빌드에 문제가 있다"는 메일이 올 수 있습니다. 오면 내용을 그대로 보여주세요. 대개 권한이나 아이콘 같은 형식 문제라 고쳐서 다시 올리면 됩니다.
