⑤ v2.0.1 공개 여부

5 결정만 하시면 됩니다 1분

지난번에 서명·공증까지 마친 v2.0.1이 GitHub에 비공개(draft) 상태로 올라가 있습니다. 지금은 아무도 받을 수 없습니다.

선택결과
A. 지금 공개 웹에서 바로 받을 수 있게 됩니다. 다만 한/영 지원과 캘린더 동기화가 빠진 버전이고, 번들 ID도 옛날 것(com.Greenday.app)입니다. 받은 사람은 나중에 새 버전을 설치할 때 옛 앱을 따로 지워야 합니다.
B. 기다렸다 v2.1.0으로 권장 새 기능과 새 번들 ID를 한 번에 담아 공개. 첫인상도 좋고, 사용자가 앱을 두 번 지우고 설치하는 일도 없습니다.

A를 고르시면 이 명령입니다:

gh release edit v2.0.1 --draft=false --latest
미리 말씀드리면 — 공개하는 순간 GitHub Actions가 한 번 돌고 빨간 X로 실패합니다. 배포용 시크릿을 등록하지 않으셨기 때문인데, 이건 고장이 아닙니다. 릴리스 파일은 이미 다 올라가 있어서 사용자 다운로드에는 아무 영향이 없습니다. 워크플로가 시작하자마자 "시크릿 없음"으로 스스로 멈추는 것뿐입니다.

⑥ 실제 계정으로 동기화 테스트

6 제가 못 하는 검증 약 10분 · 권장

캘린더 동기화 코드는 387개 테스트로 검증했지만, 그건 전부 가짜 서버를 상대로 한 것입니다. 진짜 Apple 서버에 붙는 것만은 사장님 계정으로만 확인할 수 있습니다 — 제가 사장님 Apple ID로 로그인할 수는 없기 때문입니다.

  1. account.apple.com에서 앱 암호를 하나 새로 발급 (이름: Greenday 캘린더)
    이전에 만드신 앱 암호를 재사용하셔도 됩니다. 앱마다 따로 만들면 나중에 하나만 취소하기 쉬워서 새로 만드는 걸 권합니다.
  2. Greenday 실행 → 설정 → 캘린더 동기화
  3. Apple ID와 방금 만든 앱 암호 입력 → 연결 확인
  4. 캘린더 목록이 뜨면 하나 고르기 (미리알림은 목록에 안 나옵니다 — 일정을 담을 수 없어서 제외했습니다)
  5. 마감일이 있는 할 일을 하나 만들고 → 지금 동기화
  6. iPhone 캘린더 앱에서 그 할 일이 보이는지 확인

확인해 주셨으면 하는 것:

  • 한글 제목이 깨지지 않는지 (줄바꿈 규칙을 바이트 단위로 처리했는데, 실제 애플 서버 반응은 확인이 필요합니다)
  • 종일 할 일이 하루짜리로 보이는지 (이틀에 걸쳐 보이면 알려주세요)
  • 할 일을 수정하고 다시 동기화했을 때 새 일정이 생기지 않고 기존 게 바뀌는지

안 되는 게 있으면 화면에 나온 오류 문구를 그대로 알려주세요. 오류마다 다른 안내가 나오게 해 뒀습니다.
