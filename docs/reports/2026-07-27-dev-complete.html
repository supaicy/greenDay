▣ QA 체크리스트 (앱에서 직접)

Mac 잠금으로 자동 QA를 못 해 로직만 검증된 상태입니다. 아래를 눈으로 확인해 주세요.

1. AI 패널 · 프라이버시

  • 로컬 Ollama일 때 배지가 “온디바이스”(초록), 툴팁에 → localhost.
  • 외부 provider(OpenAI 등)로 바꾸면 배지가 “외부 · api.openai.com”(호박색)으로 host 노출.
  • 헤더 아래 “전송 데이터 미리보기 · N건” 펼치면 실제 전송 태스크 목록(제목/마감/우선순위/태그)이 보임.

2. 원클릭 모델 설치 실다운로드 주의

  • 설정 > AI, Ollama 연결됨 + 추천(EXAONE/EEVE) 미설치 시 “한국어 모델 설치 (exaone3.5)” 버튼 표시.
  • 버튼 클릭 → 진행률 바 + 상태(“내려받는 중… NN%”) 갱신 → 완료 시 초록 “설치 완료”.
  • 완료 후 모델 드롭다운에 새 모델 등장 + 자동 선택(‘(미설치)’로 안 보임), “· 한국어 추천” 라벨.
  • Ollama 미연결이면 버튼 대신 수동 안내(ollama pull exaone3.5).
이 버튼은 실제로 수 GB 모델을 내려받습니다. 네트워크/디스크 상태에서 테스트하세요.

3. AI 기존-할일 액션 파괴적 — 확인 필수

  • 큰 모델(8B+/gpt-oss:20b 등) 설정 상태에서 채팅에 “○○ 완료 처리해줘” → 확인 카드 → [확인] 시 해당 할일 완료됨.
  • “○○ 내일로 미뤄줘” → 카드에 “마감일을 YYYY-MM-DD로 변경” → [확인] 시 마감일 반영.
  • “○○ 삭제해” → 빨간 [확인] 버튼 → 휴지통으로 이동(되돌리기 가능).
  • [취소] 누르면 “취소했어요”만 뜨고 아무 변경 없음.
  • 대상 못 찾으면 “…할일을 찾지 못했어요”, reschedule에 날짜 없으면 “며칠로 옮길지…” 안내.
  • 3B 모델(llama3.2)에선 액션 자동감지가 꺼짐(일반 채팅으로 처리) — 의도된 게이트.
  • 일반 질문 “오늘 완료한 거 알려줘”는 액션으로 오인되지 않고 정상 답변.

4. 태스크 / 뷰 (회귀 확인)

  • 배치 선택 ‘전체 선택’이 하위작업을 제외(리스트/스마트/전체/완료 뷰 모두, 화면과 일치).
  • 상세 패널을 넓게 + AI 챗 동시 열기 → 가운데 목록이 0으로 눌리지 않음.
  • 상세 패널 알림/반복(PickerRow) 토글 열림/닫힘·저장 정상.
  • 캘린더 드래그(주/일 시간블록, 월 날짜 이동)·리스트↔캘린더 드롭 정상(MIME 상수화 회귀).
