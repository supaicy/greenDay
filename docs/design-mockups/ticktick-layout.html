키스토어 백업 절차

키스토어는 앱 서명의 핵심. 유출 시 앱 업데이트 불가하므로 오프라인 백업 필수.

1. keytool -genkey -v -keystore haru.jks

2. Play Console → 앱 서명 키 등록

3. SHA-1 / SHA-256 지문을 Firebase 콘솔에 등록

4. .jks + 비밀번호를 1Password & 외장 SSD 2곳에 백업
